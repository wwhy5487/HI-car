# HI-car

```
A 4w mini car with some special features such as RGB lights,Ultrasonic sensor,
Screens and audio. deploy anywhere!

```

innovation idea:

```

i always want to make a small robot that can moves around with a cam to interact 
with the surroundings,so i have this idea,to make an esp32 cam car that have built
in creative features.i plan to deploy at my school library to make the surrounding 
a little bit fun in a such high stress campus.

```
